## 为什么是 TalkArena？
很多人不是“没能力”，而是：
- 关键场合会紧张，脑子一片空白；
- 话说出口才后悔，不知道怎么接更体面；
- 看了很多沟通技巧，但真实场景依然不会用。

**TalkArena 的目标很直接：**
让你在高压社交场景里反复练、低成本试错、实时被纠正，最终把表达力变成可迁移的硬技能。

---

## 🔥 核心卖点

### 1) 场景真：不是闲聊，是“实战局”
- 家庭饭桌局（长辈节奏、亲戚追问）
- 商务饭局局（资源博弈、边界拿捏）
- 群面竞争局（高压应答、短时说服）

### 2) 角色多：不是 1v1，是多人联动施压
- 一个主导节奏、一个旁观补刀、一个气氛推波助澜；
- 角色有明确人设、目的和说话风格；
- 你面对的是“社交系统”，不是单一机器人。

### 3) 反馈快：边练边改，及时救场
- 实时情绪/状态分析（文本 + 语音 + 表情）
- 对话过程动态评分（自信度、平静度、紧张度等）
- 一键“救场建议”：给你当下最好接法，不再卡壳。

### 4) 复盘全：有分数、有点评、有成长路径
- 多维度打分 + 综合点评；
- NPC 视角“内心 OS”；
- 从“这句说砸了”到“下次怎么赢”的闭环训练。

---

## 👀 你将获得什么
- **更稳的临场状态**：压力越大，越能说清楚重点；
- **更强的表达结构**：知道何时解释、何时转场、何时反问；
- **更高的社交胜率**：把“会说话”变成可复制的方法。

---

## 🧠 技术亮点（简版）
- **FastAPI + 多 Agent 编排**：稳定推进多人角色对话；
- **结构化输出约束**：降低模型跑偏和格式崩溃；
- **多模态融合**：文本、语音、表情信号统一建模；
- **TTS 语音流水线预取**：减少等待，提升沉浸感；
- **会话快照恢复机制**：增强长对话鲁棒性。

## 🚀 本地运行

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
创建 `.env`（或通过系统环境变量注入），至少包含：
- `SILICONFLOW_API_KEY`

可选：
- `SILICONFLOW_BASE_URL`
- `LLM_MODEL`
- `TALKARENA_FAST_MODE=1`

### 3. 启动服务
```bash
python main.py
```

默认访问：
- 本地：`http://127.0.0.1:8000`
- 线上：`https://talk-arena.vercel.app/`
